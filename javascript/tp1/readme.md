## Travail en TP


Pour répondre aux exercices, vous écrirez votre code dans le fichier `/scripts/exercice1.js` et vous utiliserez `console.log()` pour visualiser les résultats de vos évaluations dans la console du navigateur.  
Pendant le travail du TP, pour visualiser le résultat de votre travail, vous devez charger le fichier `/html/exercice1.html` dans *Firefox* et consulter la trace d'exécution dans la console qui s'active par `Ctrl Shift K`.

A chaque modification de votre fichier `/scripts/exercice1.js`, il vous suffira de recharger la page dans le navigateur (*F5*) pour observer la nouvelle trace d'exécution dans la console.  

Pour vous permettre d'expérimenter ce fonctionnement, le fichier `/scripts/exercice1.js contient un "bloc" marqué EXERCICE 1 qui présente les réponses à l'exercice 1 du sujet et illustrent comment rédiger les réponses au exercices au sein de ce fichier.  

Votre travail consiste donc à compléter ce fichier `/scripts/exercice1.js` avec vos réponses aux différentes questions. 


Vous pouvez bien sûr, en complément, évaluer des expressions directement dans la console.
